A vertical TikTok video about one tiny agent-built game — "Sprout Siege", a garden-defense game — shown at the exact same moment on the day it was made and after seven days of daily updates: same map, same start, same still camera, wildly more alive the second time. The video was art-directed, animated and rendered frame by frame by the agent (the renderer lives in `tools/`), ends with make.fun's referral end card, and is posted publicly on TikTok; `VIDEO.json` names the post and `main.ts` hands that address to the grader. The finished video is in `media/`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
